1)git diff показывает между текущими несохраненными изменениями и последним коммитом
git show показывает информацию о каком то коммите
git log показывает историю коммитов
2)git log -S"def" ищет коммит где было задействовано def
git blame показывает кто когда и в каком коммите добавил каждую строчку файла
