1)git diff показывает между текущими несохраненными изменениями и последним коммитом
git show показывает информацию о каком то коммите
git log показывает историю коммитов
2)git log -S"def" ищет коммит где было задействовано def
git blame показывает кто когда и в каком коммите добавил каждую строчку файла


git restore --source=HEAD~2 lab03/calc.py - возвращает файл из старого коммита(2 назад)
git restore lab03/calc.py возвращает к последнему коммиту

git reset --hard - удаляет коммиты из истории и стирает изменения
revert - отменяет изменения, создавая новый коммит и делает обратные действия

ветка - подвижный указатель на коммит, позволяет парраллельно вести работу
тег - неподвижная метка которая привязана к конкретному коммиту
