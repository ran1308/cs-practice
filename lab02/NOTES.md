рабочая папка-папка где ты работаешь с файлами
индекс-промежуточная щона между гит едд и коммитом
коммит-сохранение изменений в истории гит
Git-  система контроля версий
Git hub-сервис для хранения репозиториев
git status- показывает состояние файлов
git diff-показывает разницу между рабочей папкой и индексом
git diff -staged- разницу между индексом и коммитом
 # Ветки
ветка-отдельная линия разработки,позволяющая работать над изменениями не трогая основную версию
при новом коммите ветка сдвигается вперед указыва на последний коммит
слияние обьединение из одной ветки в другую
